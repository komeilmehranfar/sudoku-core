# Security Policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| 4.x     | Yes       |
| < 4.0   | No        |

Security fixes are released only for the latest 4.x version. Please upgrade to the latest release before reporting.

## Reporting a vulnerability

Do not open a public issue, discussion or pull request for a security vulnerability.

Report vulnerabilities privately through GitHub private vulnerability reporting:

https://github.com/komeilmehranfar/sudoku-core/security/advisories/new

Please include:

- The affected version(s)
- A description of the issue and its impact (for example, denial of service from a crafted board)
- Steps or code to reproduce, including the input board if relevant
- Any suggested fix or mitigation

## What to expect

This project is maintained on a best-effort basis. You will get an acknowledgement as soon as possible and updates as the report is assessed and fixed. Once a fix is released, a GitHub security advisory will be published. Reporters are credited unless they ask not to be.
