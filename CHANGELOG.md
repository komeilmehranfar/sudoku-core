# Changelog

All notable changes to this project are documented here. From v4 on, entries are generated by [release-please](https://github.com/googleapis/release-please) from [Conventional Commits](https://www.conventionalcommits.org/).

## 4.0.0

A new engine: human-logic solving with 31 named techniques and ten difficulty levels.

### ⚠ Breaking changes

- **Difficulty values are `"L1"`–`"L10"`.** `"easy"`, `"medium"`, `"hard"`, `"expert"` and `"master"` are gone. v3 only used techniques up to Hidden Pair, so v3 puzzles fall within `L1`–`L6`. See the README's level table to choose new values.
- **`Update.filledValue` is optional.** Elimination updates carry only `eliminatedCandidate`.
- **`SolvingStep.type` adds `"add"`**, which is only produced by `teachHint` when a player's pencil marks are missing a candidate.
- **Ratings change.** The same board can get a different level than in v3, because levels now follow the hardest technique required.

### Features

- 25 new techniques: Naked Triple and Quad, Hidden Triple and Quad, X-Wing, Swordfish, Jellyfish and their finned forms, Skyscraper, Two-String Kite, Crane, Y-Wing, W-Wing, XYZ-Wing, WXYZ-Wing, Empty Rectangle, Unique Rectangle, Simple Colouring, BUG+1, X-Chain, XY-Chain, 3D Medusa, AIC and Nishio.
- `generate(difficulty, { seed })` for deterministic puzzles, plus `timeoutMs` and `maxAttempts`.
- `analyze()` reports `hardestTechnique`, `hardestRank` and `tedium`.
- `teachHint`, `applyTeachStep` and `candidatesFromBoard` for teaching UIs, including pencil-mark checks.
- `isUniqueSolution`, `hasAnySolution` and `getUniqueSolution`.
- `generateExamplesForTactic` and `LEARN_TARGETS` for building technique lessons.
- `TACTICS`, `DIFFICULTIES` and `CELL_COUNT` exports.

### Unchanged

- `analyze`, `generate`, `solve` and `hint` keep their names and return shapes.
- Technique titles from v3 (for example `"Single Candidate Strategy"`) and the `error` message strings.
